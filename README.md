# 🍕 AA Restaurant Ordering System

A simple Python-based Restaurant Ordering System for beginners.

## 📌 Project Overview

This project allows users to order food items from a restaurant menu. The program checks whether the selected item is available and calculates the total order amount.

## 🛠️ Technologies Used

* Python
* Dictionary
* Conditional Statements
* User Input
* f-Strings

## 🍽️ Menu

| Item   | Price |
| ------ | ----: |
| Pizza  |  ₹120 |
| Pasta  |   ₹50 |
| Burger |   ₹70 |
| Salad  |   ₹50 |
| Coffee |  ₹100 |

## ⚙️ Features

* Displays the restaurant menu
* Takes food item from the user
* Checks item availability
* Allows the user to order a second item
* Calculates the total order amount
* Displays the final bill amount

## ▶️ How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder.
4. Run the following command:

```bash
python restaurant.py
```
